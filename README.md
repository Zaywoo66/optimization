# Memory Pilot

Бесплатная локальная утилита для Windows 11. Показывает доступную ОЗУ, основные процессы и изменение памяти после настройки. Открывает штатные настройки экономии памяти Brave и автозагрузки Windows.

## Запуск

Дважды щёлкните `start.cmd`. В репозитории уже есть готовый `bin/memory-pilot.exe` для Windows x64: откроется компактный монитор в консоли. Если бинарника нет, скрипт использует локальную сборку Rust или графическую PowerShell-версию. `start.cmd snapshot` делает один замер для проверки. Контрольная сумма бинарника указана в `bin/SHA256SUMS.txt`. Права администратора не нужны.

## Rust-версия

Для самостоятельной сборки нужен [Rust](https://rustup.rs/). В папке проекта выполните `cargo build --release`, затем запустите `target/release/memory-pilot.exe`. Команда `bin/memory-pilot.exe snapshot` выдаёт один замер, `watch` обновляет его каждые 5 секунд, а `brave-settings` открывает Memory Saver Brave. Rust-версия измеряет память, но не завершает и не «подрезает» процессы.

В графической версии:

1. Нажмите **Запомнить состояние**.
2. Нажмите **Настроить Brave** и включите **Memory Saver**. Для вкладок, которые должны работать постоянно, добавьте исключения.
3. Вернитесь в Memory Pilot и посмотрите разницу. Сравнивайте показатели при похожем наборе открытых приложений и вкладок.

Memory Saver освобождает память неактивных вкладок и перезагружает их при возвращении. Memory Pilot не завершает процессы, не меняет системные службы и не «очищает RAM» принудительно. Он не может изменить внутреннее потребление активной вкладки или ChatGPT/Codex. Сумма памяти процессов в таблице приблизительна, потому что общие страницы могут учитываться несколько раз; для оценки запаса используйте показатель **Доступно**.

## Расширение для Brave

В папке `extension/` находится необязательное расширение, которое может **выгружать давно неиспользуемые вкладки**. По умолчанию оно выключено. Оно пропускает активные, закреплённые, звучащие, уже выгруженные и инкогнито-вкладки, а также сайты из списка защиты. При возвращении вкладка перезагрузится; несохранённый текст на сайте может пропасть, поэтому добавьте рабочие сайты в список защиты. `chatgpt.com`, `openai.com`, Google Docs и Office защищены по умолчанию. На отдельное приложение ChatGPT/Codex расширение не влияет.

Для установки откройте в Brave `brave://extensions`, включите режим разработчика, выберите **Загрузить распакованное расширение** и укажите папку `extension/`. Затем откройте значок Memory Pilot, задайте время и включите выгрузку. Кнопка **Проверить сейчас** применяет те же правила сразу. Расширение не отправляет список вкладок в сеть; хранит настройки и число выгруженных вкладок локально.

Проверка логики расширения: `node --test extension/policy.test.cjs`.

Исходный код доступен в репозитории и не требует внешних пакетов. Утилита не отправляет данные в сеть и не запускается автоматически с Windows. Код распространяется по лицензии MIT; см. [LICENSE](LICENSE).
