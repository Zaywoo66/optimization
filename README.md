# Memory Pilot

Бесплатная локальная утилита для Windows 11. Показывает доступную ОЗУ, основные процессы и изменение памяти после настройки. Открывает штатные настройки экономии памяти Brave и автозагрузки Windows.

## Запуск

Дважды щёлкните `start.cmd`. В репозитории уже есть готовый `bin/memory-pilot.exe` для Windows x64: откроется компактный монитор в консоли. Если бинарника нет, скрипт использует локальную сборку Rust; если нет и её, попросит выполнить `cargo build --release`. `start.cmd snapshot` делает один замер для проверки. Контрольная сумма бинарника указана в `bin/SHA256SUMS.txt`. Права администратора не нужны. Старая графическая PowerShell-версия оставлена в исходниках для истории и больше не запускается через `start.cmd`.

## Rust-версия

Для самостоятельной сборки нужен [Rust](https://rustup.rs/). В папке проекта выполните `cargo build --release`, затем запустите `target/release/memory-pilot.exe`. Команда `bin/memory-pilot.exe snapshot` выдаёт один замер, `watch` обновляет его каждые 5 секунд, а `brave-settings` открывает Memory Saver Brave. `bin/memory-pilot.exe compare` запоминает состояние Brave, Chrome, Opera, ChatGPT/Codex и доступной ОЗУ, ждёт Enter после одного изменения и показывает разницу. Измерение не доказывает причину изменений: фоновые процессы тоже меняют потребление. Rust-версия не завершает и не «подрезает» процессы.

В графической версии:

1. Нажмите **Запомнить состояние**.
2. Нажмите **Настроить Brave** и включите **Memory Saver**. Для вкладок, которые должны работать постоянно, добавьте исключения.
3. Вернитесь в Memory Pilot и посмотрите разницу. Сравнивайте показатели при похожем наборе открытых приложений и вкладок.

Memory Saver освобождает память неактивных вкладок и перезагружает их при возвращении. Memory Pilot не завершает процессы, не меняет системные службы и не «очищает RAM» принудительно. Он не может изменить внутреннее потребление активной вкладки или ChatGPT/Codex. Сумма памяти процессов в таблице приблизительна, потому что общие страницы могут учитываться несколько раз; для оценки запаса используйте показатель **Доступно**.

## Расширение для Brave

В папке `extension/` находится необязательное расширение, которое может **выгружать давно неиспользуемые вкладки**. По умолчанию автоматический режим выключен. Он пропускает активные, закреплённые, звучащие, уже выгруженные и инкогнито-вкладки, сайты из списка защиты и все известные вкладки ИИ. При возвращении вкладка перезагрузится; несохранённый текст на сайте может пропасть, поэтому добавьте рабочие сайты в список защиты. Отдельная кнопка вручную выгружает фоновые вкладки ChatGPT, Claude, Gemini и Perplexity, если к ним не возвращались два часа. Она действует даже при выключенном автоматическом режиме и может прервать генерацию в фоне: нажимайте её после завершения работы. На отдельное приложение ChatGPT/Codex расширение не влияет.

Для установки откройте в Brave `brave://extensions`, включите режим разработчика, выберите **Загрузить распакованное расширение** и укажите папку `extension/`. Затем откройте значок Memory Pilot, задайте время и включите выгрузку. Кнопка **Проверить сейчас** применяет те же правила сразу. Расширение не отправляет список вкладок в сеть; хранит настройки и число выгруженных вкладок локально.

Проверка логики расширения: `node --test extension/policy.test.cjs`. Для воспроизводимого замера в отдельном временном профиле Brave: `node extension/benchmark.mjs "C:\Program Files\BraveSoftware\Brave-Browser\Application\brave.exe"`. Скрипт загружает четыре искусственные вкладки примерно по 16 МиБ данных, выгружает их и измеряет сумму рабочих наборов дочерних процессов Brave до и после. Это показывает эффект для данного теста, а не гарантированную экономию для любых сайтов или активных агентов. Для личного набора приложений используйте `compare` и повторяйте измерение при одинаковой нагрузке.

## Версии

- `v0.2`: монитор переписан на Rust; его собственное потребление в предыдущем замере снизилось примерно со 110 до 8 МиБ.
- `v0.3`: необязательная выгрузка фоновых вкладок Brave.
- `v0.4`: ручная выгрузка старых веб-вкладок ИИ, сравнение памяти до и после в Rust, повторяемый тест Brave. Активные настольные агенты ChatGPT/Codex не ограничиваются: без поддержки самого приложения внешняя утилита не может гарантировать снижение их памяти без риска прервать задачу.
- `v0.4.1`: запуск только Rust-версии; старый PowerShell-монитор больше не включается как резервный вариант.

Исходный код доступен в репозитории и не требует внешних пакетов. Утилита не отправляет данные в сеть и не запускается автоматически с Windows. Код распространяется по лицензии MIT; см. [LICENSE](LICENSE).
